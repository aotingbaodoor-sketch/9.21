# 工厂供应链阶段验收（2026-09-22）

## 角色入口

- 管理员：合作工厂管理中创建工厂和独立账号；审核工厂产品及公司销售价；销售订单拆分采购订单后分配跟单人员。
- 工厂：供货产品录入并提交审核；工厂订单中确认供货价和交期，提交各生产节点数量/实际时间/说明，再上传照片或视频。返工结果必须由工厂账号提交。
- 跟单：管理员创建“跟单员”账号，分配订单后进入“我的跟单任务”；审核工厂反馈，处理异常、质检及返工复核，确认分批发货和买方签收凭据。
- 销售：仅查看自己的客户和销售订单；不能查看工厂确认价，不能审核工厂反馈或代签收。

## 实际运行结果

`tests/quoting.integration.ts` 和 `tests/supply.scenario.ts` 使用独立临时 PostgreSQL 与随机密码运行，共 20 组通过。不会向真实业务库写入演示数据。

增加数据库直接访问防护：仅针对CRM表启用RLS，撤销公共、anon和authenticated角色的直接权限。独立数据库中已验证，即使误授予匿名角色SELECT权限，也无法读取管理员记录。后端表所有者连接保留正常业务功能；服务端仍按员工角色和负责人授权。

新增同一产品完整链路：工厂A自行录入供货产品/价格和计价规则 → 管理员核准销售价 → 销售A报价和SVG示意图 → 客户确认 → 销售订单拆分 → 工厂A接单 → 工厂A反馈和照片上传 → 跟单A审核 → 质检失败 → 工厂A提交返工 → 跟单A复核/复检 → 最终包装审核 → 两批发货 → 两次签收 → 订单关闭。

已验证销售B、工厂B、跟单B访问订单/反馈/附件被拒绝；工厂不能自审、代质检或签收；累计数量超限被拒绝；同一包装并发创建两批发货只有一次成功；返工未关闭、包装未审或高风险异常未解决均阻止发货。桌面和390px手机基础操作测试通过。历史报价/PDF、重启持久化和独立数据库恢复测试通过。

## 不等同于已完成的事项

- 新反馈审核/返工/包装/发货已做 API 集成测试，尚需完整跨设备逐表单点击验收；视频真实编码播放未验收。

- 所有测试价格、货运价、公司资料都是人工构造的测试数据，不可用于商业报价。
