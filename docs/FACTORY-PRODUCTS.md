# 工厂产品、图片与审核操作

## 管理员

1. 左侧菜单可独立上下滚动；手机先点“菜单”。进入“合作工厂管理”，建立合作工厂并绑定独立工厂账号。
2. 在“工厂产品审核”查看工厂提交的产品、规格、尺寸、包装、图片及供货规则。
3. 单独填写公司销售指导价、最低销售价、包装销售价；如有面积档位、构成项或选配，还需逐项填写销售价。系统不自动按工厂成本加成，也不接受工厂提交的销售价格。
4. 价格空白表示未配置，0表示明确不收费。核准真实资料后点击“审核通过并发布”；退回时必须写明原因。

## 工厂账号

1. 登录后只有“供货产品”和“工厂订单”，不能访问客户或其他工厂。
2. 在“供货产品”点击“录入供货产品”，选择计价方式，录入基础供货价、交期、有效期、尺寸、标准规格、选配及包装参数。数据不完整时可保存草稿，但不能提交审核。
3. 支持按面积、面积加选配、按樘、按套、按件、按延米、整行固定总价、面积档位、材料构成、组合构成。面积档位必须按上限递增；材料/组合使用明确的计量依据、系数和成本。
4. 包装重量、厚度和成本均须核对；无固定重量或无包装费用的项填0，不要留空。缺失这些参数不能作为已完整配置的产品提交。
5. 保存后在产品卡片上传PNG/JPEG/WebP，单张不超过2MB，每个产品当前最多12张。可用“编辑产品及计价规则”移除不再展示的图片。旧图片记录保留供追溯，不做不可恢复删除。
6. 点击“提交公司审核”。待审核时不可编辑；退回后可修改并重新提交。
7. 已发布的产品需先点“发起修订”。修改供货价或图片后再次提交，公司通过前销售目录仍保留旧版本；不影响已经保存的报价和PDF。

## 销售账号

报价管理的产品目录只展示公司发布的版本，附带已批准的产品缩略图。普通销售不获得供货成本和未审核图片，报价仍由后端计算。没有真实价格、完整包装/运价或必要审批时，不能以测试价格代替正式配置。

## 图片存储与上线边界

当前图片通过登录后端读取，存入PostgreSQL并纳入备份；不依赖本机磁盘图片路径，不是公开文件地址。新增图片表启用RLS并撤销匿名/前端认证角色直接访问。旧外部图片地址保留但不自动加载，需重新上传文件。

这不代表Supabase Storage或正式HTTPS已完成连接。正式数据库、私有对象存储、大规模图片容量及真实供应链数据仍需分别验收；测试价格和测试账号只应出现在隔离测试环境。
